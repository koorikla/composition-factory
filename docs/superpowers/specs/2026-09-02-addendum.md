# Architectural Addendum — 2026-09-02

## 1. System Overview & Technology Stack

- **Engine Core (`internal/emit`)**: Pure Go compiler emitting byte-identical, deterministic Crossplane Composition, XRD, functions.yaml, and RBAC artifacts across CLI (`cf gen`), HTTP API (`cf serve`), and stdio MCP (`cf mcp`).
- **Intermediate Representation (`factory.crossplane.io/v1alpha1 Blueprint`)**: Single source of truth.
- **Frontend (`web-proto`)**: Native ES module canvas architecture with pure DOM/SVG rendering, zero build-step requirement, and sub-millisecond local interaction cycles.
- **Multi-Engine Emission**:
  - `gotpl`: Go-templating functions (`function-go-templating`) with support for inline and FileSystem folder export.
  - `kcl`: KCL functions (`function-kcl` with typed `KCLInput`).
  - `python`: Python functions (`function-python` with typed `fnv1` RunFunctionRequest/Response).
- **Packaging & Adoption**:
  - `cf package` & `cf push`: OCI Crossplane Configuration (`.xpkg`) packaging and distribution.
  - `cf adopt`: Ingestion and reverse-compilation of existing Crossplane compositions into canonical blueprints.

## 2. Milestone Status

All MVP milestones (M1 Engine, M2 CLI & Cache, M3 Canvas & Live Discovery, M4 Adoption & Extensions, M5 Multi-Engine & Polish) are completed and verified across unit, contract, and BDD test suites.
