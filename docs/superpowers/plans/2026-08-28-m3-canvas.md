# compositionfactory M3 — Canvas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A node-graph canvas where dropping a managed resource, drawing a wire, and editing a field writes a blueprint and shows the Composition it generates — the product's central claim, made real.

**Architecture:** React + `@xyflow/react`, developed entirely against a **frozen API contract** rather than a running server. The contract lives as typed fixtures that Mock Service Worker serves in dev and tests, and that M2's Go HTTP tests assert against — so a contract change breaks a build rather than silently rendering a stale shape. State is a single zustand store holding one blueprint document; every mutation goes through it, and the generated YAML is whatever `POST /api/generate` returns for that document.

**Tech Stack:** React 19 · `@xyflow/react` 12 (MIT) · `@rjsf/core` 6 with `validator-ajv8` · CodeMirror 6 · zustand 5 + immer · `@dagrejs/dagre` · Vite 8 · Vitest + Testing Library · MSW 2

**Spec:** [`docs/superpowers/specs/2026-08-27-compositionfactory-design.md`](../specs/2026-08-27-compositionfactory-design.md) — read §3, §4, §7, §11.
**API contract:** [`docs/superpowers/plans/2026-08-28-m2-schema-api.md`](2026-08-28-m2-schema-api.md) — Tasks 4–6 define every route this plan consumes.
**Visual reference:** [`docs/design/canvas-prototype.html`](../../design/canvas-prototype.html) — the interaction model, already reviewed. M3 makes it real.

## Global Constraints

- **The contract is frozen here and shared.** Fixtures live in `web/src/api/fixtures/*.json`. M2's Go tests assert the same files. Neither side may change a fixture unilaterally — a change is a contract change and must land in both.
- **No generation logic in the frontend, ever.** YAML comes only from `POST /api/generate`. A client-side emitter would diverge from `cf gen` and destroy the guarantee that the canvas, the CLI and MCP produce identical output.
- **Design direction: "Schematic Instrument."** Hairline rules, monospace for all data, colour used only to encode meaning. Typography is IBM Plex Sans / Mono / Sans Condensed. Never introduce a decorative accent colour.
- **Wire colour is semantic, not decorative:** `--wire-xrd` blue (an XRD spec field flowing down), `--shared` gold (a shared var or convention), `--wire-status` teal (a status read from a sibling), `--wire-ref` rust and **dashed** (a native `*Ref`, resolved by the provider controller). The dash matters: rust and gold sit ~35° apart in hue, so the distinction must not rest on colour alone.
- **Three-state theming.** `:root` carries the complete light palette; `@media (prefers-color-scheme: dark)` guarded as `:root:not([data-theme="light"])` redefines only tokens; `:root[data-theme="dark"]` redefines them again. Never define a colour solely inside a media or `[data-theme]` block.
- **Required-first is the default everywhere a schema is rendered.** An EC2 `Instance` has 263 properties; a form that opens on all of them is unusable. The API's `required_only`, `max_depth` and `prefix` levers exist for this — use them rather than fetching everything and filtering client-side.
- Accessibility: visible keyboard focus, `prefers-reduced-motion` respected, and no state conveyed by colour alone.
- No network in tests. MSW intercepts everything; a test that reaches the network is a defect.

## The frozen contract

Every route this plan consumes, exactly as M2 Tasks 4–6 define them:

```
GET    /api/kinds?q=&limit=                          -> {"kinds":[Kind]}
GET    /api/kinds/{apiVersion}/{kind}                -> {"kind":Kind,"envelope":[Field]}
GET    /api/kinds/{apiVersion}/{kind}/fields
         ?required_only=&max_depth=&prefix=&q=&limit= -> {"fields":[Field],"total":n}
GET    /api/blueprint                                -> Blueprint
POST   /api/blueprint/parameters                     <- {"name","parameter"}
PUT    /api/blueprint/parameters/{name}              <- {"parameter"}
POST   /api/blueprint/parameters/{name}/rename       <- {"to"}
DELETE /api/blueprint/parameters/{name}
POST   /api/generate                                 <- {"write":bool}
                                                     -> {"outputs":[{"path","bytes"}],"written":bool}
```

`{apiVersion}` is URL-escaped because it contains a slash. Errors are always `{"error":"..."}` with `Content-Type: application/json`. Status codes carry meaning: 400 malformed or invalid, **409 conflicts with current state**, 404 unknown, 200 success.

```ts
// mirrors internal/index.Kind and internal/index.Field exactly
type Kind  = { kind: string; group: string; version: string; apiVersion: string;
               plural: string; scope: "Namespaced" | "Cluster"; provider: string;
               namespaced: boolean; required: number; fields: number }
type Field = { path: string; type: string; description: string;
               required: boolean; depth: number }
```

## Task 2: The blueprint store

**Files:**
- Create: `web/src/store/blueprint.ts`, `web/src/store/blueprint.test.ts`

**Interfaces:**
- Produces:
  ```ts
  type Node = { id: string; kind: string; apiVersion: string; name: string; x: number; y: number }
  type Wire = { id: string; fromParam: string; toNode: string; toPath: string }
  type State = {
    doc: Blueprint | null
    nodes: Node[]
    wires: Wire[]
    load(): Promise<void>
    addNode(k: Kind, x: number, y: number): void
    moveNode(id: string, x: number, y: number): void
    removeNode(id: string): void
    connect(fromParam: string, toNode: string, toPath: string): void
    disconnect(wireId: string): void
    undo(): void
    canUndo(): boolean
  }
  ```

**Two rules this task locks in:**
1. **A wire is not decoration — it *is* `{from: params.X}` on a resource field.** `connect` writes that into the document; `disconnect` removes it. There is no separate wire model to drift.
2. **Node positions are mirrored into the document on drag *end*, never on drag move** — otherwise every pointer event becomes an undo entry and Ctrl+Z rewinds one pixel.

    const s = useBlueprint.getState()
    s.addNode(queueKind, 0, 0)
    const nodeId = useBlueprint.getState().nodes[0].id
    s.connect("maxMessageSize", nodeId, "maxMessageSize")

    expect(useBlueprint.getState().wires).toHaveLength(0)

    s.addNode(queueKind, 0, 0)
    expect(useBlueprint.getState().canUndo()).toBe(true)

    const s = useBlueprint.getState()
    s.addNode(queueKind, 0, 0)
    const id = useBlueprint.getState().nodes[0].id
    for (let i = 0; i < 50; i++) s.moveNode(id, i, i)
    let steps = 0
    while (useBlueprint.getState().canUndo() && steps < 60) { useBlueprint.getState().undo(); steps++ }
    expect(steps).toBeLessThan(5)

- [ ] **Step 3: Write the implementation**

Create `web/src/store/blueprint.ts` satisfying the Interfaces block. Requirements:

- zustand with immer. One `doc`, plus derived `nodes`/`wires` kept in sync with it.
- Undo is a bounded snapshot stack (cap around 50). `moveNode` updates position without pushing a snapshot; a single snapshot is pushed on drag end by the canvas calling an explicit commit.
- Resource names must be unique and stable — the name becomes `setResourceNameAnnotation`, and a duplicate silently collapses resources in Crossplane. Derive from the kind, lowercased, with a numeric suffix on collision.

- `removeNode` removes the resource and every wire touching it.

Requirements:

- `wires.ts` owns the mapping in both directions and the colour rule. `wireStyle` returns CSS variables, never literals, so the theme system remains the single source of colour.
- `ResourceNode` shows kind, resource name, apiVersion, and one port per *bound or required* field — not all 18. A node whose fields exceed the visible count shows a `+N more` affordance rather than silently truncating.

- Nodes are focusable and respond to Delete/Backspace. `prefers-reduced-motion` disables any transition.
- Wire creation: dragging from an XR parameter port to a resource field port calls `connect`. A drop on an incompatible target is refused visibly rather than silently ignored.
- Position is written to the store on drag **end** only.
- Use `@dagrejs/dagre` for an initial auto-layout when a document loads with no stored positions.
