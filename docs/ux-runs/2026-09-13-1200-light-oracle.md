## 4. Mission M1 — Blank Start to Encrypted S3 Bucket Wire & Generate

**Objective**: Starting from a blank document, discover the AWS S3 provider, install it, add a `Bucket` onto the canvas, define and wire a `region` parameter from the composite XR, and generate Crossplane manifests.

- On page load, the starter examples dialog appears offering sample blueprints.

- Switching to the **KINDS** tab, searching `bucket` lists `Bucket` under `S3.AWS.M.UPBOUND.IO` (along with sub-resources like `BucketAcl`, `BucketCorsConfiguration`, `BucketLifecycleConfiguration`, etc.).

- In **Manifest** view, `ESSENTIALS` highlights the single required field: `region string` (marked with red asterisk).
- Switching to the **Fields** view exposes all schema fields with type badges and wire actions.
- **Screenshots**:
  - `12-inspector-initial.png`

#### Step 6: Wiring XR Parameter via "__new__" Inline Form

- Submitting the form persists parameter `region` to the blueprint's XRD spec and automatically connects `Bucket.region` to `params.region`.
- The inline form cleanly collapses and the bound chip `<- params.region` is displayed.
- **Screenshots**:

#### Step 7: Canvas Wiring Topology
