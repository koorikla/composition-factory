there mandatory. Generated XRD:

```yaml

              providerName:
                type: string
```

and the Composition still dereferences it straight from the XR spec:

`get xdatabases` — the exact cost CF-474 named. Reproduced twice: two `cf gen` runs from the
same starter, `diff -r` byte-identical. Filed as **CF-476**, with a comment on #380.
