## 4. Mission M1 — first contact: an S3 bucket, from nothing

**Outcome: completed with workaround.** Time from blank document to the generated
Composition: ~31 min of driver wall-clock (most of it spent writing the driver,
not hunting the UI). Validate is unavailable here (Docker absent, CF-093), so the
mission stops at Generate as the prompt directs.

### Narrative

Arrival on a blank document puts the **starter-blueprint chooser** in front of
you before you have done anything — a 12-card modal, "Choose an Example
Blueprint". For someone who arrived wanting to build their own thing it is an
interruption, but it is honestly labelled and it is dismissible three ways, all
of which I checked on separate fresh loads: `Escape`, a click on the dim overlay,
and the `×` at top right. All three close it. (An earlier run of mine reported it
undismissable; that was my own broken predicate, not the product.)

Provider search does find `s3` by the word a user knows: typing `s3` into
`Search kinds…` filters straight to `Bucket`, `BucketACL`, `BucketPolicy` and the
other 22 S3 kinds. Dragging the first `Bucket` row onto the canvas worked on the
first attempt and did three things without being asked: it created the card, it
**declared the source** in the blueprint (`sources: [provider: ghcr.io/…/provider-aws-s3:v2.7.0]`),
and it pre-filled `region: us-east-1` as a literal. The auto-declared source is
the right call — a user who drags a kind has not thought about `sources` and
should not have to.

Adding the parameter was the only place I fumbled, and the fumble is mine: the
parameter list is sorted alphabetically and re-sorts on the fly as you type, so a
driver holding a positional index edits the wrong row. A human watching the
screen would not hit this. Worth noting for whoever writes specs against the
parameter list: index by value, not by position.

Wiring is discoverable: each card's field rows are ports with a coloured dot, and
dragging the XRD's `region` port onto the Bucket's `region` port drew the wire
and rewrote the field to `from: params.region`. The literal `us-east-1` was
replaced silently — correct behaviour, but the value is gone with no note.

`Validate` reports honestly rather than lying:

```
validation check unavailable
…": executable file not found in $PATH 💡 Environment Fix Tip: Install Crossplane CLI on host:
brew install crossplane-cli (macOS) or curl -sL https://cli.crossplane.io/stable/current/install.sh | sh
```

`Generate` puts up a confirm dialog naming the output directory
("Generate will write manifests to disk in '.testrun-ux/out'. Proceed?") and then
writes `compositions/`, `xrds/`, `providerconfigs/aws.yaml` and `functions.yaml`.

### Oracle

Met, except Validate. The XRD declares the parameter with its type:

```yaml
              providerName: {type: string, description: '…'}
              region:
                type: string
            required: [providerName]
```

and the Composition's Bucket takes its region from the XR parameter:

```yaml
          apiVersion: s3.aws.m.upbound.io/v1beta1
          kind: Bucket
          spec:
            forProvider:
              {{- if or (hasKey $spec "region") }}
              {{- if hasKey $spec "region" }}
              region: {{ $spec.region | quote }}
              {{- end }}
              {{- else }}
              {}
              {{- end }}
```

### Round-trip

Re-importing the generated `compositions/xapps.platform.example.org.yaml` through
the UI (Import → native file chooser → confirm "Import will replace doc.cf.yaml
(undoable)") reproduced the canvas exactly: `xrd` + `bucket`, one wire, the same
`region: from: params.region`. Every loss was **named**, not swallowed:


This is the Round-Trip Rule behaving as `AGENTS.md` §1 asks, including the
suggested remedy. No console errors, no page errors, at any phase.

## 8. Observations that are not findings

Recorded so they are not re-raised, and so the judgement is auditable:

- **Redundant emitted guard.** The wired optional field emits
  `{{- if or (hasKey $spec "region") }}` wrapping a second, identical
  `{{- if hasKey $spec "region" }}`. `or` with one argument is the argument, so
  the outer test is a no-op and the inner one is unreachable-as-distinct. The
  output is *correct*; this is generated-YAML noise, not a moment where the tool
  did the wrong thing, so it is a style observation and not filed.
- **Kinds from undeclared providers on a blank document.** With a seeded cache
  and `sources: []`, KINDS lists all 25 S3 and all SQS kinds while SOURCES says
  "No sources declared." That is what CF-472 (#370, closed 2026-09-12 22:18,
  outside this window) deliberately left in place: deferral applies only when the
  blueprint *does* declare sources.
- **Literal lost on wiring.** Dropping a wire onto a field that already holds a
  literal replaces it with no note. Reversible by undo; not filed.
- **Parameter list re-sorts while you type.** Cost falls on scripted drivers, not
  on humans. Noted for spec authors, not filed.
- **The starter chooser opens on arrival.** Dismissible three ways; honest about
  what each card does ("replaces doc.cf.yaml · undoable"). A judgement call about
  first contact, not a defect.
