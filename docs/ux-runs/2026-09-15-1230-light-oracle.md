### Generated Manifest Verification

Inspection of `out/compositions/xapps.platform.example.org.yaml` confirmed accurate Crossplane composition semantics:

```yaml
          {{- if hasKey (dig "resources" "role" "resource" "status" "atProvider" dict $.observed) "arn" }}
          ---
          apiVersion: v1
          kind: ServiceAccount
          metadata:
            name: {{ $xr }}-service-account
            annotations:
              {{ setResourceNameAnnotation "service-account" }}
              {{- if hasKey (dig "resources" "role" "resource" "status" "atProvider" dict $.observed) "arn" }}
              'eks.amazonaws.com/role-arn': {{ (index $.observed.resources "role").resource.status.atProvider.arn | quote }}
              {{- end }}
          {{- end }}
```

Key validations:
- **Ordering**: Role is declared before ServiceAccount in the composition pipeline.
- **Envelope Guard**: The ServiceAccount resource block is enclosed in an `if hasKey ... "arn"` condition to prevent reconciliation before the Role ARN is reported by the cloud provider.
- **Value Guard & Quoting**: Inside metadata annotations, `'eks.amazonaws.com/role-arn'` is safely quoted using Go templating `quote` and guarded by `hasKey`.
