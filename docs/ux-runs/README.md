# UX Run Reports

Findings from agents that used the canvas as a person would, rather than as a test suite
does. Produced by the `canvas-ux-tester` skill (`.claude/skills/canvas-ux-tester`).

One file per run: `YYYY-MM-DD-<mission>.md`, screenshots beside it. Each report names its
mission and outcome, narrates the run, and lists severity-ordered findings — every P0 and
P1 pinned to a spec in `tests/` that fails until it is fixed.

These are observations, not decisions. A report never ticks a `BACKLOG.md` item; it gives
the driver the evidence to.
