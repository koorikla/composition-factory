## 3. Mission M1 — first contact: an S3 bucket, from nothing

Blank start, no blueprint, naive eye. Stopped at Generate (Validate is unavailable
without Docker, CF-093).

**Oracle: met.** The generated Composition carries an S3 `Bucket` whose `region` comes
from the XR parameter, and the XRD declares that parameter with its type:

```yaml
              region:
                type: string
            required: [providerName]
```

```
          spec:
            forProvider:
              {{- if or (hasKey $spec "region") }}
              {{- if hasKey $spec "region" }}
              region: {{ $spec.region | quote }}
              {{- end }}
              {{- else }}
              {}
              {{- end }}
```

Validate reads `validation check unavailable`; `cf gen --validate` reports
`render check unavailable: crossplane CLI not found on PATH`. Both are environment.

### What the first contact was like

Good, and better than the watch-list feared:

- **Arrival** is a modal, *Choose an Example Blueprint*, covering the canvas — nine
  starters including *AWS S3 Secure Storage Bucket*, which is M1's goal verbatim. It
  helps and interrupts in equal measure: it must be dismissed before the canvas can be
  touched, and a user who wants to build rather than load has to find the `×` first.
- Behind it the empty canvas names its own next step and links the two panels that
  serve it — *1. Drag kinds from KINDS  2. Add cloud providers in SOURCES*.
- **Provider search finds `s3` by the word a user knows.** Typing `s3` into
  *Providers catalogue* returns `provider-aws-s3`, `provider-aws-s3control`,
  `provider-aws-s3vectors`, each with an `Add` button — no package name required.
- **The first drag is discoverable and does more than it promises.** Dropping `Bucket`
  onto the canvas auto-declared the source: *Installed providers* went 1 → 2 and
  `provider-aws-s3:v2.7.0` appeared without a separate Add step.
- **Schema fetching is accounted for.** The KINDS footer reads *Drag a kind onto the
  canvas. Schemas load per-kind — 4.5 KB median.*
- The Inspector puts `REGION` under **ESSENTIALS** immediately, with `Val`/`Wire`/`Raw`
  and a `us-east-1` default — the parameter to wire is the first thing offered.
- `Wire → + new XRD parameter…` opens an inline name field that closes on submit and
  leaves `region ← params.region` (CF-475's lingering form is gone).
- Generate confirms before writing (`Generate will write manifests to disk in '…'.
  Proceed?`) and wrote 4 files; the drawer switched from *3 previews* to *4 written*.

Two truncation observations, **neither filed**: the KINDS rows ellipsize so that
`BucketA…` stands for four different kinds, but every row carries a full
`title` tooltip (`BucketAccelerateConfiguration · s3.aws.m.upbound.io/v1beta1 (…)`)
and the full name is in `data-kind`. That is polish with a mitigation, not a moment
where the tool did the wrong thing.

## 4. Things ruled out, and why

Recorded so the next run does not re-chase them:

- **Four `Bucket` nodes from one drag.** Leftover in-memory document state from an
  earlier scripted session against the same `cf serve`, not a duplicate-drop bug. On a
  freshly started server, instrumenting `window.addEventListener('drop', …, true)`
  gave `BROWSER drop EVENTS DISPATCHED: 1` and `/api/blueprint` held exactly one
  resource.
- **Generate writing nothing.** `output.js:916-921` gates the write behind
  `window.confirm`; Playwright auto-dismisses dialogs. With the dialog accepted, all
  four files landed. Test-harness artifact.
- **A wordless `⚠️` warning banner.** `#render-warn-banner` carries `hidden=""` and an
  empty `#render-warn-text`; it was never shown. Reading it via `innerText` was the
  error.
