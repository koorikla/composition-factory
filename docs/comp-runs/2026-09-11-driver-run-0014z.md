## Lesson for the routine

A session-level API usage limit kills every subagent at once and the driver with them; the
locks then hold `in-progress` on issues nobody is working. Another driver instance ignored
the locks and landed the branches, which happened to be correct here but is exactly the
collision the lock exists to prevent. The routine should say what a driver does when it finds
an `in-progress` lock older than the 75-minute subagent cap with no branch pushed under it.
