# CompositionFactory Emitted Template Dialect Specification

**Status:** authoritative reference · **Date:** 2026-09-02 · **Applies to:** `internal/emit`, `internal/manifest`

This document defines the exact dialect of `function-go-templating` templates generated by `composition-factory`. It serves as the single specification for both template emission and manifest parsing/splicing.

---

## 1. Dialect Forms Table

| Form ID | Name | Emitted Shape | Matcher / Pattern | Notes |
|---|---|---|---|---|
| **F1** | **Prelude** | `{{- $spec := .observed.composite.resource.spec -}}\n{{- $xr := .observed.composite.resource.metadata.name -}}\n{{- $xrMeta := .observed.composite.resource.metadata -}}` | `^\{\{- \$spec := .*?\}\}\n\{\{- \$xr := .*?\}\}\n\{\{- \$xrMeta := .*?\}\}` | Establishes top-level shortcuts for composite resource spec and metadata. |
| **F2** | **Define Block** | `{{- define "<name>" -}}\n<template-body>\n{{- end -}}` | `\{\{- define "(?P<name>[^"]+)" -\}\}(?P<body>[\s\S]*?)\{\{- end -\}\}` | Helper sub-templates (e.g. IAM policies, complex JSON/YAML snippets). |
| **F3** | **Document Header** | `---\napiVersion: <group>/<version>\nkind: <kind>\nmetadata:\n  annotations:\n    {{ setResourceNameAnnotation "<name>" }}` | `(?:^\|\n)---\napiVersion:\s+(?P<api>[^\n]+)\nkind:\s+(?P<kind>[^\n]+)\nmetadata:\s*\n\s+annotations:\s*\n\s+\{\{ setResourceNameAnnotation "(?P<name>[^"]+)" \}\}` | Resource boundary and Crossplane composition resource naming. |
| **F4** | **Literal Field** | `indent<key>: '<val>'` / `<key>: <num/bool>` | `^(?P<indent>\s*)(?P<key>[a-zA-Z0-9_.-]+):\s*(?P<val>'[^']*'\|"[^"]*"\|true\|false\|\d+|\[.*?\]\|\{.*?\})` | Scalar, list, or inline map literal. |
| **F5** | **Parameter Wire** | `indent<key>: {{ $spec.<param> }}` | `^(?P<indent>\s*)(?P<key>[a-zA-Z0-9_.-]+):\s*\{\{\s*\$spec\.(?P<param>[a-zA-Z0-9_.-]+)\s*\}\}` | Direct dereference of a required composite parameter. |
| **F6** | **Guarded Optional Field** | `{{- if hasKey $spec "<param>" }}\nindent<key>: {{ $spec.<param> }}\n{{- end }}` | `\{\{- if hasKey \$spec "(?P<param>[^"]+)" \}\}\n(?P<indent>\s*)(?P<key>[a-zA-Z0-9_.-]+):\s*\{\{\s*\$spec\.[a-zA-Z0-9_.-]+\s*\}\}\n\{\{- end \}\}` | Optional parameter binding with guard avoiding `missingkey=error`. |
| **F7** | **Status Wire Guard Chain** | `{{- if and (hasKey $.observed.resources "<res>") ... }}\nindent<key>: {{ (index $.observed.resources "<res>").resource.status.atProvider.<path> }}\n{{- end }}` | `\{\{- if and \([^)]*hasKey \$\.observed\.resources "(?P<src>[^"]+)"[^)]*\)[\s\S]*?\}\}\n(?P<indent>\s*)(?P<key>[a-zA-Z0-9_.-]+):\s*\{\{\s*\(index \$\.observed\.resources "[^"]+"\)\.resource\.status\.atProvider\.(?P<path>[a-zA-Z0-9_.-]+)\s*\}\}\n\{\{- end \}\}` | Safe cross-resource status reference across reconciliation passes. |
| **F8** | **forEach Loop** | `{{- range $i, $item := $spec.<param> }}\n---\n<document-body>\n{{- end }}` | `\{\{- range \$(?P<idx>[a-zA-Z0-9_]+),\s*\$(?P<item>[a-zA-Z0-9_]+)\s*:=\s*\$spec\.(?P<param>[a-zA-Z0-9_.-]+)\s*\}\}(?P<body>[\s\S]*?)\{\{- end \}\}` | Iterated resource generation over array parameters. |
| **F9** | **when Conditional** | `{{- if <condition> }}\n---\n<document-body>\n{{- end }}` | `\{\{- if (?P<cond>[^\n]+) \}\}(?P<body>[\s\S]*?)\{\{- end \}\}` | Conditional resource generation based on parameters. |
| **F10** | **Envelope Fields** | `writeConnectionSecretToRef: ...` / `providerConfigRef: ...` / `managementPolicies: ...` | Standard Crossplane resource envelope fields under `spec.`. |
| **F11** | **Annotations Map** | `metadata:\n  annotations:\n    <key>: <val>` | `metadata:\s*\n\s+annotations:\s*\n(?P<entries>(?:\s+[^\n]+\n)+)` | Composed resource metadata annotations. |
| **F12** | **Opaque Spans** | Any text/action not matching F1–F11. | Non-matching byte range `[Start, End)` | Preserved 100% byte-exact across saves; rendered as locked cards or fields. |

---

## 2. Preservation Guarantee

1. **Identity Preservation**: A document loaded and saved without changes satisfies `Patch(Parse(doc), nil) == doc` byte-for-byte.
2. **Hunk Isolation**: An edit to field `k` produces a diff containing only the hunk containing `k`. Comments, key order, indentation, and opaque spans remain untouched.
