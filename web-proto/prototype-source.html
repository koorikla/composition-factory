What changed in this pass

  
Four things were missing, and three of them were the same missing concept: nothing was
  shared across resources, so region had to be wired once per node and a convention had
  nowhere to live.

  
    
    
  • Shared vars. region is now one binding on the Shared tab, computed once as
      $region and bound to every field named region. The XRD port shows a
      ×3 fan badge. One wire, three resources.
    • 
    
  • Conventions. naming and tags are reusable templates bound by field name, emitted as
      go-template define/include blocks. Fields they cover fill in automatically and show a
      bound chip — click Override on any one field to detach just that field.
    • 
    
  • The XRD is editable. Select XQueue: rename the kind, rename fields inline, change types from
      the dropdown, toggle required, delete, and + Add field. Renaming a field rewrites every wire that
      referenced it.
    • 
    
  • Providers are visible. The Sources tab lists each provider with its pinned digest and the
      Kubernetes version — the lockfile that makes generation reproducible. + Add provider takes an xpkg ref.
    • 
  

  
Also new: on any unbound managed-resource field, ↑ promote to XRD field creates a matching
  XRD field with the type pre-filled from the provider schema and wires it. That's the
  "suggests options from managed resources and vice versa" direction, made concrete.

  
Working with deep objects

  
    
    
  • Arrays hold more than one item. Expand containers[ ] on the Deployment and hit
      + — you get containers[1] with its own full subtree, its own ports, and its own
      YAML. Same for ports[ ] and env[ ]. Removing an item drops its field state with it.
    • 
    
  • Nodes resize. Drag the bottom-right corner of any node: wider for long paths, taller to show
      more fields. A node showing fewer fields than it has says +N more.
    • 
  

  
Still faked: dragging a wire port-to-port, and drag-from-palette. Everything else is live state —
  the YAML regenerates from it.
